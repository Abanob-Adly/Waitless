# Waitless

A modern healthcare queue management and appointment booking platform built with React, TypeScript, and Vite.

## Overview

Waitless helps patients find doctors, book appointments, manage payments, and track clinic queues in a simple and user-friendly interface.

The project focuses on providing a smooth healthcare experience through an intuitive and responsive UI.

## Tech Stack

- React
- TypeScript
- Vite
- CSS3
- HTML5

## Features

- Doctor Search
- Doctor Cards
- Clinic Locations
- Live Ticket Tracking
- Queue Management
- Payment Section
- Responsive User Interface
- Reusable Components

## Installation

Clone the repository:

git clone <repository-url>
Install dependencies:

npm install
Run development server:

npm run dev
Build for production:

npm run build
