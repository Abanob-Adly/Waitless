1. Open your terminal and make sure you're in the right directory.

2. Download dependencies:
    npm install

3. Run service:
    npm run dev 

- note i'm using nodemon with backend for auto refresh

4. run redice (using docker)
    first time: sudo docker run -d --name local-redis -p 6379:6379 redis:alpine
    later: sudo docker start local-redis

5. run ngrok
    npx ngrok http --url=cider-feline-decal.ngrok-free.dev 3000
